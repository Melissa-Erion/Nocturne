# Regimen brand assets

| File | Use |
|---|---|
| `regimen-logo-dark.png` | Logo on the dark brand background (websites, social banners, presentations) |
| `regimen-logo-light.png` | Logo on white (documents, invoices, light pages) |
| `regimen-logo-transparent-white-text.png` | Logo to place on your own dark background |
| `regimen-logo-transparent-dark-text.png` | Logo to place on your own light background |
| `regimen-icon-1024.png`, `regimen-icon-512.png`, `regimen-icon.svg` | App icon / square profile image (App Store, Google Play, favicon source) |
| `regimen-icon-google-120.png` | Google sign-in consent screen logo (120 × 120) |
| `regimen-social-avatar-400.png` | Instagram, Facebook, TikTok, X profile picture |
| `regimen-mark-transparent-512.png`, `regimen-mark.svg` | The mark on its own, no background |

Colours: purple `#9184d9`, background `#12131d`, surface `#272a3b`, text `#e9e9ed`.
Typeface: Inter Medium (free, Google Fonts), letter-spacing −1.5%.
Keep clear space around the logo equal to the height of the square. Don't stretch, recolour or add effects.
